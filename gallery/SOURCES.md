# Gallery asset provenance

24 imagined exhibition environments supplied from the project owner's ArtDuo
collection. Its source catalogue records ChatGPT Image output filenames dated
2026-04-23. These are generated environments, not photographs of named museums.

`scenes.json` records each original relative path and SHA-256, the distributed
WebP hash, dimensions, original normalized wall mount and editorial matching
tags. Background bg-015 uses ArtDuo's prepared wall-above-bench correction.
The original images are resized to 1280 px wide and encoded as WebP; no new
paintings, logos, people, or generated night variants are added.

These backgrounds are distributed as part of the owner's applications with
their permission. This change does not grant a separate standalone image
license. The repository's code license does not relicense third-party artwork.
Artwork providers and source links retain their own rights statements.

The shared code, catalogue and images in `gallery/` are versioned together.
ArtBreeze is the source copy; WaitWiki contains the same reviewed version.
Normal builds use these committed files and do not contact ArtDuo or a CDN.

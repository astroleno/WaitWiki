## 实现结果

| 问题 | 本轮行为 | 目的 |
| --- | --- | --- |
| R1 主动键盘进入丢焦点 | 入口 Enter / 空格将焦点送到正文或画廊工具；关闭时返回入口。更多菜单打开时，Esc 先关闭菜单，再关闭面板 | 键盘路径连续；自动展示继续保留 AI 输入框焦点 |
| R3 换内容整面消失 | 保留原内容、背景和位置，角落显示简短等待提示；下一项准备好后替换。失败保留原内容并可重试 | 等待期间保持空间连续性 |
| R4 长画名截断 | 默认两行墙签保留；标题/作者提供完整提示，更多菜单内可用键盘读取完整画名与作者 | 保持展陈安静，也能就地辨认作品 |
| R5 同名收藏难辨 | 阅读收藏/最近增加最多 140 个字符的正文摘录；已选条目有文字、边线及 aria-pressed 状态 | 找回指定内容无需猜选 |
| R7 观看文案 | Art 使用“最近看过 / 下次看这幅”，Wiki 使用“下次读这条” | 与两款各自的概念一致 |

系列重叠继续接受。Art 保留 24 个展厅，Wiki 保留一个可关闭的 bg-027，阅读正文继续直接显示在背景上。默认 2 秒、内容类别、非模态使用方式和现有动效不作重新设计。

## 模块与关键接口

- `gallery/companion.js`：原生按钮点击区分键盘进入与指针/自动展示；负责焦点返回、等待反馈和新内容提交。Art 先取图并解码候选作品，再替换当前内容。
- `gallery/session.js`：增加仅在内存中的 `busy / setBusy`。准备下一项时暂停自动收起和自动换轮，关闭时释放；保留指针/焦点停留规则。
- 继续通过现有 revision / loadRevision 取消过期结果。关闭、禁用、锁定当前内容或较新的请求都会使旧结果失效；失败反馈也受当前 revision 约束。
- `gallery/experience.js` 仅补充面板高度 CSS 变量，限制更多菜单高度；使用现有 Stage 和场景目录。
- `options.js`：摘录仅作为纯文本渲染；继续使用现有 reading_selection_v2 和 reading_state_v2。列表加载与选择分别有版本计数，防止较慢的旧响应抹掉新选中状态。
- 两端共享的 7 个运行文件与 2 个测试文件保持逐字节一致；目录、图片、产品标题等产品差异继续分别维护。
